# Global preferences

- Prefer clear, concise explanations. State the outcome, evidence, and relevant trade-offs.
- Inspect repository instructions and existing conventions before modifying code.
- Preserve unrelated user changes, and do not overwrite or delete work without a clear request.
- For substantial changes, provide a short plan, implement, and run relevant local checks.
- Report what was tested and what could not be verified.
- Prefer a small number of focused agents, with distinct tasks, when delegation is useful.
